Inloggen bij JD Autoservice

Tik op de knop om in te loggen:

Inloggen

Werkt de knop niet, bijvoorbeeld omdat je de app op je beginscherm hebt staan? Vul dan deze code in de app in:

{{ .Token }}

De link en de code werken één keer en een uur lang. Heb je dit niet aangevraagd? Dan kun je deze mail negeren.
